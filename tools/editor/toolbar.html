How to edit
  • Click any paragraph, heading, caption, list item or table cell and type. Links, buttons, charts and the diagram stay locked; ask Claude for structural changes.
  • Enter starts a new paragraph or list item. Shift+Enter is a line break. Backspace in an empty paragraph deletes it.
  • Ctrl/⌘+B bold, Ctrl/⌘+I italic. Pasted text comes in as plain text.
  • Amber boxes are placeholders. Replace with text swaps the box for a paragraph, Add image inserts a figure above it, Delete box removes it. The ✓ beside an amber underline marks that text as final.
  • Edits autosave in this browser only. Save working copy downloads writeup.editable.html with your edits baked in: open that file to continue on another machine, or send it to Claude. Export final downloads the clean writeup.html.
  • Changes lists what you touched, with a revert button for each. Discard all throws away every unsaved edit in this browser.
