How to edit together
  • Click any paragraph, heading, caption, list item or table cell and type. Every change is saved to this page as you go and shows up for everyone who has it open. Links, buttons, charts and the diagram stay locked; ask Claude for structural changes.
  • A name tag on a paragraph means someone else is editing it right now. If two people change the same paragraph, the last one to leave it wins, so wait for the tag to clear.
  • Enter starts a new paragraph or list item. Shift+Enter is a line break. Backspace in an empty paragraph deletes it. Ctrl/⌘+B bold, Ctrl/⌘+I italic. Pasted text comes in as plain text.
  • Amber boxes are placeholders. Replace with text swaps the box for a paragraph, Add image inserts a figure above it, Delete box removes it. The ✓ beside an amber underline marks that text as final.
  • Comment opens a comment thread on the paragraph you last clicked; comments live in this page's comment panel, not in the article.
  • Changes lists every change with who made it and a revert button. Export final downloads the clean writeup.html; Claude can also pull the current state straight from this page.
